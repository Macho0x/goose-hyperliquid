# Remaining

Signing, action maps, info requests, and subscription texts match hypersdk 0.3.0. `info::post` and `exchange::post` send those JSON bodies with goose-http. `ws::subscribe` connects to the chain's `wss` URL, sends one text, and returns the next message. The package is [goose-hyperliquid](https://github.com/Macho0x/goose-hyperliquid) `0.2.0`. Nothing is open.
